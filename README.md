# NEXORA STORE SF — sitio principal

Este repositorio publica la página principal **https://stiven20eduu.github.io/** y configura la identidad NEXORA STORE que Google puede asociar al dominio.

Tienda de recargas: https://stiven20eduu.github.io/nexora-store.sf/

Incluye favicon PNG cuadrado (512 × 512), logo oficial, metadatos, WebSite JSON-LD, robots.txt y sitemap.xml.

Si GitHub Pages no publica automáticamente: **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**.

El favicon y el nombre mostrados en Google dependen de su rastreo; no aparecen necesariamente de inmediato.
